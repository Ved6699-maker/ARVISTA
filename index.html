How ARVISTA works

  1. Allow camera access.
  2. Point the camera at a common object.
  3. The AI model checks the live video for recognizable objects.
  4. ARVISTA draws an animated effect around the detected object.

This first version uses browser-based object detection. It is a visual AR prototype rather than true world-anchored AR, so the effect follows the detected bounding box.
